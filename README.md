# 🛡️ InsuranceSage – AI Insurance Recommendation Assistant  
### A Personalized AI Chatbot for Health, Life & Education Insurance Guidance

Python • Flask • NLP • AI Prompt Compression

---

## 🧠 Overview

InsuranceSage is an AI-powered Insurance Recommendation Assistant designed to help users understand insurance concepts and receive personalized guidance for:

- 🏥 Health Insurance  
- ❤️ Life Insurance  
- 🎓 Education Insurance  

The system combines a Flask backend, NLP-based text generation, and prompt optimization using ScaleDown to deliver fast, clear, and professional recommendations.

This project focuses on insurance awareness, decision support, and dynamic user interaction.

---

## 🚀 Key Capabilities

✅ Personalized Insurance Suggestions (based on age, income, and goals)  
✅ AI-powered explanations (benefits, pros & cons)  
✅ Dynamic Web UI (HTML/CSS/JS)  
✅ Prompt Compression for efficiency  
✅ Safe backend input handling  
✅ Beginner-friendly architecture  

---

## 🎯 What This Project Does

Users can:

- Enter their age, income level, and insurance goal  
- Ask questions about insurance  
- Receive tailored recommendations  
- Learn advantages & disadvantages of each insurance type  
- Understand how insurance works in simple terms

## ✨ Features

### 🔹 AI Explanation Module

Uses NLP to generate:
